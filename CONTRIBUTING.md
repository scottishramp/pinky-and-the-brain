# Contributing

This repository is a framework: architecture, contracts, and starter skeletons. Keep it generic.

## What belongs here

- Sharper definitions of the pieces
- Contract fixes (message shapes, defer language, snapshot metadata)
- Adapter notes for a new chat platform, model, agent CLI, or runtime
- Starter-code fixes that do not assume one vendor

## What does not belong here

- Personal knowledge, addresses, phone numbers, or account fragments
- Production secrets, tokens, or allowlisted user ids
- A full copy of a private assistant
- Vendor lock-in presented as architecture

## Voice

Write as if the next reader will implement this on a different stack next week. Name vendors in the reference stack and adapter docs. Keep the contracts vendor-neutral.
